2. book 表结构与页面约束

以下依据本地 solar_notes.book 的实际 SHOW CREATE TABLE 结果，读取日期为 2026 年 11 月 17 日。本次仅查询结构，没有改表或写入数据。

字段数据库定义页面处理
idBIGINT，非空，主键；注释约定存储雪花 ID列表展示，前端使用 string；添加时不填写，后续由服务端生成。
planet_idBIGINT，非空添加表单必选真实 planet.id 字符串；列表响应以嵌套 planet 对象返回关联信息。
titleVARCHAR(50)，非空，默认空字符串；注释标明业务限长 20 个字符必填，校验前 trim，最多 20 个字符；存储上限和业务上限分开理解。
sort有符号 INT，非空，无默认值必填整数；范围 −2147483648 至 2147483647；表单默认 1。
display_statusENUM('visible', 'hidden')，非空，默认 visible显示 / 隐藏下拉框，初始选“显示”；字段值保持英文枚举。
created_atDATETIME，非空，默认 CURRENT_TIMESTAMP当前列表项不包含此字段，因此本页不展示；添加时也不填写。
updated_atDATETIME，非空，默认 CURRENT_TIMESTAMP，更新时自动更新当前列表项不包含此字段，因此本页不展示；未来需要时再扩展响应约定。

2.1 所属天体是 ID 关联，不是 name 匹配

一条书籍记录的 planet_id 对应天体表的 planet.id。当前表定义中没有外键约束，后续创建接口仍需验证天体是否存在。name 和中文 label 只用于下拉框显示；不能把 'Earth' 或 '地球' 赋给 planet_id。

现有 getBodyList() 返回已创建天体及其字符串 ID，因此直接作为选项来源。getBodyStatus() 只有名称与存在状态，没有 ID，不适合这里。已有 bodyOptions 仅用于中文名称映射，不用于生成可选天体或伪造 ID。

2.2 排序唯一性由服务端和数据库最终确认

联合唯一索引是 uk_planet_sort (planet_id, sort)。同一天体下排序值不能重复；不同天体可以使用相同排序值。即使书籍处于隐藏状态，该记录仍占用排序值，因为索引不包含显示状态。书籍标题没有唯一索引，不能据此推断禁止同名书籍。

数据库没有“必须大于 0”的约束，本例允许整个有符号 INT 范围。默认 1 只是输入初始值，不代表此值可用。当前尚未读取书籍列表，因此不做本地查重。未来即便加入前端检查，仍需处理后端返回的排序冲突。

2.3 标题长度与系统字段

页面依据表注释采用 20 字业务规则，后续书籍创建接口应保持一致。数据库的非空定义本身不会拒绝空字符串或纯空白，因此表单另外做必填、非空白校验。沿用当前表单校验库的 Unicode 码点计数，避免原生 maxlength 按 UTF-16 代码单元截断表情；组合字符仍可能由多个码点组成。

浏览器不生成书籍 ID，不填写创建时间或更新时间，也不把 ID 转成 Number。书籍表目前没有封面、作者、简介、ISBN 等字段，本次表单先按已有结构实现。

2.4 列表响应采用嵌套 planet 对象

以你当前 BookListPage.vue 的 list 为准，每条书籍响应项的顶层字段为 id、title、sort、display_status、planet。其中 planet 是必需对象，包含 id、name、title、intro；书籍 ID 和天体 ID 均使用字符串。

预期的单条书籍响应项点击折叠 / 展开
{
    id: '1000000000000000003',
    title: '太阳观测入门1',
    sort: 1,
    display_status: 'visible',
    planet: {
        id: '2000000000000000002',
        name: 'Sun',

上面的数据库字段说明用于解释存储约束；列表项采用你约定的嵌套结构，不是数据库行的逐字段复制。列表没有顶层 planet_id、planet_name、created_at、updated_at，因此类型、固定数据和表格均不再读取这些顶层字段。天体的标题和简介属于 planet，不要与书籍的 title 混淆。

添加表单继续用 addForm.planet_id 保存所选真实天体 ID。列表返回完整天体对象，不代表创建书籍时也应提交该对象。创建请求体如何封装，等后端接口确定后再对接。本次约定的是列表中的元素结构，不据此假设外层一定叫 books、list 或包含某种分页字段。

5. 提取公共函数并更新两个页面

getBodyLabel() 只依赖固定天体选项，没有组件状态。将其提取为公共函数后，天体管理和书籍管理使用同一套名称转换逻辑。按 5.1 → 5.2 → 5.3 的顺序调整。

5.1 新增公共函数：src/utils/body.js

src/constants/body.js 继续保存选项和长度常量；src/utils/body.js 导入 bodyOptions 并负责名称转换。使用普通具名函数，定义完成后再命名导出。

src/utils/body.js点击折叠 / 展开
import {bodyOptions} from '@/constants/body'

/**
 * 根据天体标识读取中文名称；未知标识保留原文。
 * @param {string} name 区分大小写的天体标识。
 * @returns {string} 中文名称或未匹配的原始标识。
 */
function getBodyLabel(name) {
    /** @type {import('@/constants/body').BodyOption} 当前天体名称映射。 */
    for (const option of bodyOptions) {
        if (option.name === name) {
            return option.label
        }
    }
    return name
}

export {getBodyLabel}

例如 getBodyLabel('Sun') 返回“太阳”，getBodyLabel('Earth') 返回“地球”；没有匹配到的名称原样返回，保持现有大小写匹配行为。

/**
 * 检查 ID 是否存在于当前成功读取的天体列表中。
 * @param {string} planetId 待检查的天体 ID。
 * @returns {boolean} 是否允许选择此天体。
 */
function isPlanetSelectable(planetId) {
    if (isPlanetLoading.value === true || planetLoadFailed.value === true || planetId === '') {
        return false
    }
    /** @type {import('@/api/body').BodyRecord} 当前天体。 */
    for (const planet of planetOptions.value) {
        if (planet.id === planetId) {
            return true
        }
    }
    return false
}

/**
 * 校验所属天体字段；不能用天体名称代替关联 ID。
 * @param {unknown} rule 当前校验规则，本函数无需读取。
 * @param {unknown} value 待校验的字段值。
 * @param {(error?: string | Error) => void} callback 校验结果回调。
 * @returns {void}
 */
function validatePlanetId(rule, value, callback) {
    if (typeof value !== 'string' || isPlanetSelectable(value) === false) {
        callback(new Error('请选择当前列表中的已创建天体'))
        return
    }
    callback()
}

/**
 * 复用现有天体列表接口；失败后仍可点击刷新重试。
 * @returns {Promise<void>} 本轮读取结束，失败状态保存在页面中。
 */
async function loadPlanetOptions() {
    if (isPlanetLoading.value === true || isValidating.value === true) {
        return
    }
    isPlanetLoading.value = true
    planetError.value = ''
    try {
        planetOptions.value = await getBodyList()
        planetLoadFailed.value = false
    } catch (error) {
        planetOptions.value = []
        planetLoadFailed.value = true
        planetError.value = getApiErrorMessage(error, '天体选项加载失败') + '，请刷新重试'
    } finally {
        isPlanetLoading.value = false
    }

    // 刷新后所选天体已不可用时，只清空关联字段，保留其他输入。
    if (addForm.planet_id !== '' && isPlanetSelectable(addForm.planet_id) === false) {
        addForm.planet_id = ''
    }
}

/**
 * 重置表单及旧校验提示；关闭抽屉或再次打开时调用。
 * @returns {void}
 */
function resetAddForm() {
    addForm.planet_id = ''
    addForm.title = ''
    addForm.sort = BOOK_DEFAULT_SORT
    addForm.display_status = 'visible'
    if (addFormRef.value !== null) {
        addFormRef.value.clearValidate()
    }
}

/**
 * 打开抽屉并刷新真实天体选项，等待表单挂载后清除旧提示。
 * @returns {Promise<void>} 抽屉打开及本轮选项读取处理结束。
 */
async function openAddDrawer() {
    if (isValidating.value === true || drawerVisible.value === true) {
        return
    }
    resetAddForm()
    drawerVisible.value = true
    /** @type {Promise<void>} 立即启动的选项读取，防止短暂使用旧数据。 */
    const loading = loadPlanetOptions()
    await nextTick()
    if (addFormRef.value !== null) {
        addFormRef.value.clearValidate()
    }
    await loading
}

/**
 * 校验期间阻止抽屉关闭。
 * @param {() => void} done 抽屉提供的关闭回调。
 * @returns {void}
 */
function beforeCloseDrawer(done) {
    if (isValidating.value === false) {
        done()
    }
}

/**
 * 响应取消按钮，实际重置由 closed 事件完成。
 * @returns {void}
 */
function closeAddDrawer() {
    if (isValidating.value === false) {
        drawerVisible.value = false
    }
}

/**
 * 校验添加表单；本阶段不发送创建请求，也不向列表追加记录。
 * @returns {Promise<void>} 本轮校验结束。
 */
async function submitBook() {
    if (isValidating.value === true || drawerVisible.value === false || addFormRef.value === null) {
        return
    }
    if (isPlanetLoading.value === true || planetLoadFailed.value === true) {
        ElMessage.warning('请先成功加载天体选项')
        return
    }

    isValidating.value = true
    try {
        addForm.title = addForm.title.trim()
        /** @type {boolean} 所有字段是否通过校验。 */
        const isValid = await addFormRef.value.validate()
        if (isValid === false) {
            return
        }
    } catch {
        // 字段错误由 el-form-item 展示，保留本次输入以便修正。
        return
    } finally {
        isValidating.value = false
    }

    // 后续在这里接入书籍创建 API；现在不关闭抽屉、不清空、不提示创建成功。
    ElMessage.info('表单校验通过；保存功能尚未开放，本次内容未保存')
}

6. 交互与错误处理说明

打开添加抽屉→读取真实天体→填写四个字段→校验→提示尚未保存，保留输入
场景页面行为
首次打开 / 每次重新打开重置上次输入，刷新天体选项；加载期间禁止选择天体和确认添加。
天体接口成功但数组为空提示先去天体管理创建天体；用户可取消抽屉，之后回来刷新选项。
天体接口失败显示错误，清空并禁用旧选项；“刷新天体选项”按钮保持可重试。
鉴权失效沿用 request.js 清理登录状态与跳转；页面不再重复弹出鉴权消息。
手动刷新后原天体不在列表中只清空 planet_id，保留标题、排序和显示状态；后续保存仍须服务端确认关联有效。
校验失败字段下方显示提示，解除操作锁，保留输入与抽屉。
校验通过明确提示内容未保存；不 push 新记录、不清空表单、不自动关闭抽屉。
取消 / 关闭抽屉closed 事件重置表单；校验期间禁止关闭，避免与本轮校验交叉。

数字输入框的 step 设为 1；没有使用 precision="0" 或 step-strictly 来隐式取整。小数会被整数规则拒绝；清空输入产生的 undefined 也会触发必填校验。组件的 min / max 可能将用户输入规范到边界，规则仍另外验证 INT 范围。

表单只确认“输入格式满足当前规则”，无法确认排序未被其他书籍占用。提示中故意区分“校验通过”和“创建成功”。

7. 后续书籍 API 接入位置

当前后端路由代码只有登录和三个天体接口，尚未注册书籍管理接口。先完成本页，再按后端最终协议增加 src/api/book.js。

  1. 列表：确定接口路径、外层响应包、分页及排序规则；列表项采用本指南约定的嵌套 planet 结构。先移除四条固定记录，将 list 初始化为 ref([])；校验每个书籍项及其 planet.id / name / title / intro 后，整体赋给 list.value。同步移除示例提示，补齐加载、失败重试和真实空列表提示；请求失败时不要回退显示示例数据。
  2. 创建：在 submitBook() 校验之后增加真实请求。根据后端协议构建请求体，只提交所属天体 ID、标题、排序和显示状态；不假设一定存在某个嵌套字段。字符串 ID 原样发送，sort 通过整数校验后按数字发送。
  3. 提交锁：当前 isValidating 只覆盖校验。接入请求后，把锁扩展到“校验 + 创建请求”，保持单层、同级的 try / catch 结构，并确保所有退出分支释放锁。
  4. 成功与失败：收到后端明确成功后再提示、关闭抽屉、重新读取列表。创建成功后列表读取失败要单独提示。超时或断网时先核对实际结果，不自动重复创建。
  5. 公共错误处理：请求复用现有 request 实例，携带 Bearer 令牌；公共错误继续交给 apiError.js。新增的书籍业务响应码加入 apiCode.js，排序冲突等页面专属说明放在书籍页面。
  6. 数据约束：服务端生成 ID，校验天体存在、标题业务长度、整数范围、枚举以及联合唯一索引冲突。列表如何排序仍需明确；当前约定的列表项不含时间字段，若未来增加，再约定其格式和时区。

建议未来按所属天体分组、组内按 sort 升序展示；这是一项待后端确认的展示约定，当前数据库索引本身不保证查询结果顺序。本阶段不添加书籍编辑、删除、筛选、分页或目录管理。

01 / SCOPE

从固定书籍示例切换到真实接口

本指南基于 2026 年 11 月 19 日的前后端源码。它接替书籍管理页面参考中的固定列表与只校验表单阶段，完成分页查询、创建书籍和新的排序规则。

以当前后端代码为准

用途HTTP 方法与完整路径结果

控制器和鉴权中间件处理的结果均为 HTTP 200，成功与否由 code 判断。网络中断或代理故障仍可能产生无响应、HTTP 5xx 等传输错误。页面拿到的已经是 payload.data，无需再次读取 response.data.data。

03 / VALIDATION

排序统一从 1 开始，与显隐无关

输入hiddenvisible
负整数拒绝拒绝
0拒绝拒绝
1 至 4294967295 的整数允许允许
空值、NaN、小数、数字字符串、超过上限拒绝拒绝

输入框使用 :min="BOOK_SORT_MIN"，其中 BOOK_SORT_MIN = 1，新表单的默认值同样为 1。控件会将越界输入限制到 min/max 范围内，例如 0 或负数会被限制到 1；具名函数 validateBookSort() 再检查模型值是否为范围内的正整数。

排序校验不读取 display_status。删除显示状态选择器上的 change 事件和原来的联动校验函数；切换显示或隐藏不会改变排序值，也不会触发排序的额外校验。小数由校验器拒绝，不使用 precision 或 step-strictly 自动取整。

排序从 1 开始，并保持唯一。 隐藏书和可见书共享同一天体下的排序位置，例如已有一本书使用 1，另一本书无论显示或隐藏都不能重复使用 1，后端返回 BOOK_SORT_OCCUPIED 时应保留表单，让管理员换值。

标题在校验和发送前 trim，最多 20 个 Unicode 码点。后端使用与 JavaScript trim 对齐的处理规则；前端不加原生 maxlength，以免表情等字符的长度计算与服务端不同。

当前后端创建请求的 sort 已改为 uint32，并通过 gte=1 校验，源码取值范围为 1 至 4294967295。列表响应也使用 uint32，读取函数按 0 至 4294967295 校验类型范围，以便仍能展示可能存在的历史 0；这不代表创建时允许 0。数据库列类型和约束也需要与正整数规则及 uint32 范围一致，本次未查询数据库或执行迁移。

5.3 扩展现有 fileReader.js

当前工程的文件名是 fileReader.js。保留原有两个字符串函数，并增加 readSafeIntegerField()，供书籍的排序和分页响应读取使用。它只做基础类型与范围检查，不包含书籍业务规则；不能用 Number(value) 将错误的字符串响应悄悄转换成数字。

完整文件src/utils/fileReader.js
/**
 * 本函数用于读取一个字符串字段,保留输入对象中的原值
 * @param {Record<string, unknown>} record 待检查的记录
 * @param {string} field 字段名
 * @returns {string} 已确认类型的字段值
 * @throws {Error} 字段缺失或类型错误时抛出
 * */
function readStringField(record, field) {
    /** @type {unknown} 待校验的字段值 */
    const value = record[field]

    if (typeof value !== 'string') {
        throw new Error('接口响应中的 ' + field + ' 字段类型异常')
    }

    return value
}

/**
 * 本函数用于读取必须非空的字符串字段
 * @param {Record<string, unknown>} record 待检查的记录
 * @param {string} field 字段名
 * @returns {string} 非空字符串
 * @throws {Error} 字段缺失/类型错误或为空时抛出
 * */
function readRequiredStringField(record, field) {
    /** @type {string} 已确认类型的字段值 */
    const value = readStringField(record, field)

    if (value === '') {
        throw new Error('接口响应中的 ' + field + ' 字段不能为空')
    }

    return value
}

/**
 * 读取指定范围内的安全整数, 不把字符串转换为数字.
 * @param {Record<string, unknown>} record 待检查的记录.
 * @param {string} field 字段名.
 * @param {number} minimum 允许的最小值.
 * @param {number} maximum 允许的最大值.
 * @returns {number} 已校验的整数.
 * @throws {Error} 字段缺失, 类型错误或超出范围时抛出.
 */
function readSafeIntegerField(record, field, minimum, maximum) {
    /** @type {unknown} 未经校验的字段值. */
    const value = record[field]
    if (typeof value !== 'number' || Number.isSafeInteger(value) === false) {
        throw new Error('接口响应中的 ' + field + ' 必须是安全整数')
    }
    if (value < minimum || value > maximum) {
        throw new Error('接口响应中的 ' + field + ' 超出允许范围')
    }
    return value
}

export {
    readStringField,
    readRequiredStringField,
    readSafeIntegerField,
}

分页总数必须能够由 JavaScript 安全表示。超出安全整数范围时明确拒绝响应，而不是展示不精确的页码或总数。书籍与天体 ID 仍走字符串读取，不使用这个数字函数。

5.4 提取分页类型和处理函数

新增 src/types/pagination.js，将公共 Pagination 类型与相关处理函数放在同一个模块中。这里同时包含 JSDoc 类型定义和实际执行的 JavaScript 函数；函数通过普通 import 导入，类型通过 JSDoc 的 import 类型引用使用。

  • validatePaginationInput()：校验页码、每页条数及偏移计算的安全范围。
  • readPagination()：读取分页对象，检查字段类型、请求参数回显和总页数。
  • validatePageItemCount()：校验接口原始列表的条数与分页信息是否一致。

模块复用分页常量、对象判断和安全整数读取工具，错误提示使用通用的“列表”表述。totalItem 表示总记录数，适用于书籍以及后续使用相同分页协议的管理页面。

完整文件src/types/pagination.js
import {PAGE_SIZE_MAX} from '@/constants/pagination'
import {isRecord} from '@/utils/typeGuard'
import {readSafeIntegerField} from '@/utils/fileReader'

/**
 * 列表响应中的公共分页信息.
 * @typedef {Object} Pagination
 * @property {number} currentPage 本次请求的页码.
 * @property {number} itemPerPage 每页条数.
 * @property {number} totalPage 总页数, 没有记录时为 0.
 * @property {number} totalItem 总记录数.
 */

/**
 * 检查列表请求的分页参数, 避免产生不精确的偏移值.
 * @param {number} currentPage 当前页码.
 * @param {number} itemPerPage 每页条数.
 * @returns {void}
 * @throws {Error} 页码, 页大小或偏移值不合法时抛出.
 */
function validatePaginationInput(currentPage, itemPerPage) {
    if (Number.isSafeInteger(currentPage) === false || currentPage < 1) {
        throw new Error('页码必须是从 1 开始的安全整数')
    }
    if (Number.isSafeInteger(itemPerPage) === false || itemPerPage < 1 || itemPerPage > PAGE_SIZE_MAX) {
        throw new Error('每页条数必须是 1 到 ' + PAGE_SIZE_MAX + ' 之间的整数')
    }
    if (currentPage - 1 > Math.floor(Number.MAX_SAFE_INTEGER / itemPerPage)) {
        throw new Error('页码过大, 无法精确计算分页位置')
    }
}

/**
 * 读取分页响应, 检查回显值和总页数是否一致.
 * @param {unknown} value 未经校验的分页对象.
 * @param {number} currentPage 请求使用的页码.
 * @param {number} itemPerPage 请求使用的每页条数.
 * @returns {Pagination} 已校验的分页对象.
 * @throws {Error} 分页字段或总数关系不合法时抛出.
 */
function readPagination(value, currentPage, itemPerPage) {
    validatePaginationInput(currentPage, itemPerPage)

    if (isRecord(value) === false) {
        throw new Error('列表响应缺少 pagination 对象')
    }

    /** @type {Pagination} 四个字段都必须是安全整数. */
    const pagination = {
        currentPage: readSafeIntegerField(value, 'currentPage', 1, Number.MAX_SAFE_INTEGER),
        itemPerPage: readSafeIntegerField(value, 'itemPerPage', 1, PAGE_SIZE_MAX),
        totalPage: readSafeIntegerField(value, 'totalPage', 0, Number.MAX_SAFE_INTEGER),
        totalItem: readSafeIntegerField(value, 'totalItem', 0, Number.MAX_SAFE_INTEGER),
    }
    if (pagination.currentPage !== currentPage || pagination.itemPerPage !== itemPerPage) {
        throw new Error('列表响应的分页参数与请求不一致')
    }

    /** @type {number} 根据总条数计算的页数, 空列表为 0. */
    let expectedTotalPage = 0
    if (pagination.totalItem > 0) {
        expectedTotalPage = Math.floor((pagination.totalItem - 1) / itemPerPage) + 1
    }
    if (pagination.totalPage !== expectedTotalPage) {
        throw new Error('列表的总页数与总条数不一致')
    }
    return pagination
}

/**
 * 校验完整分页列表的条数, 要求列表与总数来自同一数据快照.
 * @param {number} itemCount 接口原始列表的条数, 未经页面筛选.
 * @param {Pagination} pagination 已通过 readPagination 校验的分页信息.
 * @returns {void}
 * @throws {Error} 条数无效或与分页信息不一致时抛出.
 */
function validatePageItemCount(itemCount, pagination) {
    if (Number.isSafeInteger(itemCount) === false || itemCount < 0) {
        throw new Error('列表条数必须是非负安全整数')
    }

    /** @type {number} 当前页的偏移值, 分页参数已通过安全范围检查. */
    const offset = (pagination.currentPage - 1) * pagination.itemPerPage
    /** @type {number} 当前数据快照应返回的本页条数. */
    const expectedCount = Math.min(pagination.itemPerPage, Math.max(pagination.totalItem - offset, 0))
    if (itemCount !== expectedCount) {
        throw new Error('列表条数与分页信息不一致')
    }
}

export {
    validatePaginationInput,
    readPagination,
    validatePageItemCount,
}

条数一致性校验要求列表和总数来自同一数据快照。当前书籍接口满足该条件，因此可以使用；调用时传入接口原始数组的 length 和已经过 readPagination() 校验的结果。空表和越界页的预期条数都是 0。

src/constants/pagination.js 负责公共配置，本模块负责分页类型与数据处理。页面中的翻页、加载状态、错误展示和越界后重新请求仍由组件管理。

getBookList(currentPage, itemPerPage) 返回已校验的 {books, pagination}。书籍字段由本模块读取，分页参数、分页响应和条数一致性由第 5.4 节的公共模块校验，并保持服务端的顺序。addBook(form) 只接收已通过页面业务校验的输入，负责请求映射与成功响应检查。

import request from '@/utils/request'
import {isRecord} from '@/utils/typeGuard'
import {readRequiredStringField, readSafeIntegerField, readStringField} from '@/utils/fileReader'
import {BOOK_SORT_MAX} from '@/constants/book'
import {readPagination, validatePageItemCount, validatePaginationInput} from '@/types/pagination'

/**
 * 书籍列表中的一条记录, 保留后端的嵌套天体结构.
 * @typedef {Object} BookRecord
 * @property {string} id 书籍 ID, 不转换为 Number.
 * @property {string} title 书籍标题.
 * @property {number} sort 排序值, 列表读取按后端 uint32 类型校验.
 * @property {import('@/constants/book').BookDisplayStatus} display_status 显示状态.
 * @property {import('@/api/body').BodyRecord} planet 所属天体.
 */

/**
 * 已完成字段校验的书籍列表结果.
 * @typedef {Object} BookListResult
 * @property {BookRecord[]} books 当前页的书籍, 保留服务端顺序.
 * @property {import('@/types/pagination').Pagination} pagination 分页信息.
 */

/**
 * 已通过页面校验的创建输入, API 模块负责转换请求体结构.
 * @typedef {Object} CreateBookInput
 * @property {string} planet_id 真实天体 ID, 保留字符串.
 * @property {string} title 书籍标题.
 * @property {number} sort 排序正整数, visible 和 hidden 均从 1 开始.
 * @property {import('@/constants/book').BookDisplayStatus} display_status 显示状态.
 */

/**
 * 读取书籍记录, 同时检查嵌套的天体字段.
 * @param {unknown} value 未经校验的书籍记录.
 * @returns {BookRecord} 已校验的书籍记录.
 * @throws {Error} 书籍或天体字段缺失, 类型错误时抛出.
 */
function readBook(value) {
    if (isRecord(value) === false || isRecord(value.planet) === false) {
        throw new Error('书籍记录或所属天体格式异常')
    }

    /** @type {string} 保留原值的书籍 ID. */
    const id = readRequiredStringField(value, 'id')
    /** @type {string} 书籍标题, 列表读取不修改历史内容. */
    const title = readStringField(value, 'title')
    /** @type {number} 列表排序值, 兼容已有的 0, 新建表单必须从 1 开始. */
    const sort = readSafeIntegerField(value, 'sort', 0, BOOK_SORT_MAX)
    /** @type {string} 待检查的显示状态. */
    const displayStatus = readRequiredStringField(value, 'display_status')
    if (displayStatus !== 'visible' && displayStatus !== 'hidden') {
        throw new Error('书籍显示状态必须是 visible 或 hidden')
    }

    /** @type {import('@/api/body').BodyRecord} 完整的所属天体, 未知名称原样保留. */
    const planet = {
        id: readRequiredStringField(value.planet, 'id'),
        name: readRequiredStringField(value.planet, 'name'),
        title: readStringField(value.planet, 'title'),
        intro: readStringField(value.planet, 'intro'),
    }

    return {
        id: id,
        title: title,
        sort: sort,
        display_status: displayStatus,
        planet: planet,
    }
}

/**
 * 使用 POST 请求一页书籍, 校验数据后保持服务端排序返回.
 * @param {number} currentPage 从 1 开始的页码.
 * @param {number} itemPerPage 每页条数, 使用公共分页模块校验范围.
 * @returns {Promise<BookListResult>} 当前页记录和分页信息.
 * @throws {Error} 入参或响应格式不合法时拒绝, 业务及网络错误直接向外传递.
 */
async function getBookList(currentPage, itemPerPage) {
    validatePaginationInput(currentPage, itemPerPage)

    /** @type {{pagination: {currentPage: number, itemPerPage: number}}} 后端要求的请求体. */
    const body = {
        pagination: {
            currentPage: currentPage,
            itemPerPage: itemPerPage,
        },
    }
    /** @type {unknown} 公共请求模块已经解包后的 data. */
    const data = await request.post('/v1/book/list', body)
    if (isRecord(data) === false || Array.isArray(data.books) === false) {
        throw new Error('书籍列表响应缺少 books 数组')
    }

    /** @type {import('@/types/pagination').Pagination} 已校验的分页信息. */
    const pagination = readPagination(data.pagination, currentPage, itemPerPage)
    validatePageItemCount(data.books.length, pagination)

    /** @type {BookRecord[]} 当前页记录, 不重新排序. */
    const books = []
    /** @type {unknown} 未经校验的当前记录. */
    for (const item of data.books) {
        books.push(readBook(item))
    }

    return {
        books: books,
        pagination: pagination,
    }
}

/**
 * 将已校验的表单映射为后端创建请求, 成功响应不包含新书籍或 ID.
 * @param {CreateBookInput} form 已通过页面业务规则校验的输入.
 * @returns {Promise<void>} 服务端已确认创建成功.
 * @throws {Error} 成功响应格式异常时拒绝, 业务及网络错误直接向外传递.
 */
async function addBook(form) {
    /**
     * @type {{book: {title: string, sort: number, display_status: import('@/constants/book').BookDisplayStatus, planet: {id: string}}}}
     * 后端要求的嵌套请求体, 只引用天体 ID.
     */
    const body = {
        book: {
            title: form.title.trim(),
            sort: form.sort,
            display_status: form.display_status,
            planet: {
                id: form.planet_id,
            },
        },
    }
    /** @type {unknown} 创建成功时, 解包后的 data 是空对象. */
    const data = await request.post('/v1/book/create', body)
    if (isRecord(data) === false) {
        throw new Error('创建书籍响应格式异常, 请刷新列表确认结果')
    }
}

export {
    getBookList,
    addBook,
}

创建成功的 data 是空对象，没有可追加到列表的新记录。页面会在确认成功后重新读取列表。列表完整性校验依据后端在同一个只读事务中统计总数并读取当前页的实现；读取越界页时，返回空数组是正常情况。

/**
 * 读取指定页, 加载期间禁止并发翻页. 越界时最多补读一次有效末页.
 * @param {number} currentPage 请求页码.
 * @param {number} itemPerPage 请求每页条数.
 * @returns {Promise<void>} 本轮读取处理结束, 失败信息记录在页面状态中.
 */
async function loadBooks(currentPage, itemPerPage) {
    if (isLoading.value === true || isSubmitting.value === true) {
        return
    }
    isLoading.value = true
    loadFailed.value = false
    listError.value = ''
    list.value = []
    pagination.currentPage = currentPage
    pagination.itemPerPage = itemPerPage
    try {
        /** @type {import('@/api/book').BookListResult} 本轮列表结果. */
        let result = await getBookList(currentPage, itemPerPage)
        if (result.pagination.totalPage > 0 && currentPage > result.pagination.totalPage) {
            result = await getBookList(result.pagination.totalPage, itemPerPage)
        }
        if (
            result.pagination.totalPage > 0 &&
            result.pagination.currentPage > result.pagination.totalPage
        ) {
            pagination.currentPage = result.pagination.totalPage
            loadFailed.value = true
            listError.value = '列表在读取期间发生变化, 请刷新重试'
            return
        }
        list.value = result.books
        pagination.currentPage = result.pagination.currentPage
        pagination.itemPerPage = result.pagination.itemPerPage
        pagination.totalPage = result.pagination.totalPage
        pagination.totalItem = result.pagination.totalItem
        if (pagination.totalItem === 0) {
            pagination.currentPage = 1
        }
    } catch (error) {
        loadFailed.value = true
        listError.value = getBookErrorMessage(error, '书籍列表加载失败') + ', 请刷新重试'
    } finally {
        isLoading.value = false
    }
}

}

/**
 * 修改每页条数时回到第一页.
 * @param {number} size 新的每页条数.
 * @returns {Promise<void>} 本轮读取结束.
 */
async function changePageSize(size) {
    if (isLoading.value === true || isSubmitting.value === true || size === pagination.itemPerPage) {
        return
    }
    await loadBooks(1, size)
}

/**
 * 本函数用于检查选定的天体 ID 是否存在于当前成功读取的天体列表中
 * @param {string} planetId 待检查的天体 ID
 * @returns {boolean} 是否允许选择此天体
 * */
function isPlanetSelectable(planetId) {
    if (isPlanetLoading.value === true) {
        return false
    }

    if (planetLoadFailed.value === true) {
        return false
    }

    if (planetId === '') {
        return false
    }

    /** @type {import('@/api/body').BodyRecord} 当前天体 */
    for (const planet of planetOptions.value) {
        if (planet.id === planetId) {
            return true
        }
    }

    return false
}

/**
 * 本函数用于校验所属天体字段: 不能用天体名称代替关联 ID
 * @param {unknown} rule 当前校验规则,本函数无需读取
 * @param {unknown} value 待校验的字段值
 * @param {(error?: string | Error) => void} callback 校验结果回调
 * @returns {void}
 * */
function validatePlanetId(rule, value, callback) {
    if (typeof value !== 'string') {
        callback(new Error('请选择当前列表中的已创建天体'))
        return
    }

    if (isPlanetSelectable(value) === false) {
        callback(new Error('请选择当前列表中的已创建天体'))
        return
    }

    callback()
}

/**
 * 本函数用于请求天体列表接口(失败后仍可点击刷新重试)
 * @returns {Promise<void>} 本轮读取结束,失败状态保存在页面中
 * */
async function loadPlanetOptions() {
    if (isPlanetLoading.value === true) {
        return
    }

    if (isSubmitting.value === true) {
        return
    }

    isPlanetLoading.value = true
    planetError.value = ''
    try {
        planetOptions.value = await getBodyList()
        planetLoadFailed.value = false
    } catch (error) {
        planetOptions.value = []
        planetLoadFailed.value = true
        planetError.value = getApiErrorMessage(error, '天体选项加载失败') + ',请刷新重试'
    } finally {
        isPlanetLoading.value = false
    }

    // 刷新后所选天体已不可用时,则只清空关联字段,保留其他输入
    if (addForm.planet_id !== '' && isPlanetSelectable(addForm.planet_id) === false) {
        addForm.planet_id = ''
    }
}

/**
 * 本函数用于重置表单及旧校验提示(关闭抽屉或再次打开时调用)
 * @returns {void}
 * */
function resetAddForm() {
    addForm.planet_id = ''
    addForm.title = ''
    addForm.sort = BOOK_DEFAULT_SORT
    addForm.display_status = 'visible'

    if (addFormRef.value !== null) {
        addFormRef.value.clearValidate()
    }
}

/**
 * 本函数用于打开抽屉并请求天体列表接口,等待表单挂载后清除旧提示
 * @returns {Promise<void>} 抽屉打开及本轮选项读取处理结束
 * */
async function openAddDrawer() {
    if (isLoading.value === true) {
        return
    }
    if (isSubmitting.value === true) {
        return
    }

    if (drawerVisible.value === true) {
        return
    }

    resetAddForm()

    drawerVisible.value = true
    /** @type {Promise<void>} 立即启动的选项读取,防止短暂使用旧数据 */
    const loading = loadPlanetOptions()
    await nextTick()

    if (addFormRef.value !== null) {
        addFormRef.value.clearValidate()
    }

    await loading
}

/**
 * 本函数用于在校验和创建请求期间阻止抽屉关闭
 * @param {() => void} done 抽屉提供的关闭回调
 * @returns {void}
 * */
function beforeCloseDrawer(done) {
    if (isSubmitting.value === false) {
        done()
    }
}

/**
 * 本函数用于响应取消按钮,实际重置由 closed 事件完成
 * @returns {void}
 * */
function closeAddDrawer() {
    if (isSubmitting.value === false) {
        drawerVisible.value = false
    }
}

/**
 * 校验并创建书籍, 创建请求结束后再执行列表或天体选项刷新.
 * @returns {Promise<void>} 本次提交及必要的读取处理结束.
 */
async function submitBook() {
    if (isSubmitting.value === true || isLoading.value === true || drawerVisible.value === false || addFormRef.value === null) {
        return
    }
    if (isPlanetLoading.value === true || planetLoadFailed.value === true) {
        ElMessage.warning('请先成功加载天体选项')
        return
    }

    isSubmitting.value = true
    try {
        addForm.title = addForm.title.trim()
        /** @type {boolean} 当前表单是否有效. */
        const isValid = await addFormRef.value.validate()
        if (isValid === false) {
            isSubmitting.value = false
            return
        }
    } catch {
        isSubmitting.value = false
        return
    }
    if (typeof addForm.sort !== 'number') {
        isSubmitting.value = false
        return
    }

    /** @type {import('@/api/book').CreateBookInput} 已校验的本次提交快照. */
    const input = {
        planet_id: addForm.planet_id,
        title: addForm.title,
        sort: addForm.sort,
        display_status: addForm.display_status,
    }
    /** @type {boolean} 后端是否明确确认创建成功. */
    let created = false
    /** @type {boolean} 是否需要重新读取天体选项. */
    let reloadPlanets = false
    /** @type {boolean} 创建结果是否尚未确认. */
    let resultUnknown = false
    try {
        await addBook(input)
        created = true
    } catch (error) {
        if (isAuthError(error) === true) {
            return
        }
        /** @type {number | undefined} 可识别的业务错误码. */
        const code = getApiErrorCode(error)
        if (code === undefined) {
            resultUnknown = true
            ElMessage.warning('尚未确认创建结果, 请核对刷新后的列表再决定是否重试')
        } else {
            ElMessage.error(getBookErrorMessage(error, '创建书籍失败'))
        }
        reloadPlanets = code === API_CODE.BOOK_PLANET_NOT_FOUND
    } finally {
        isSubmitting.value = false
    }

    if (created === true) {
        drawerVisible.value = false
        ElMessage.success('书籍创建成功')
        // 创建已经成功. 列表刷新失败只显示列表错误, 不会改成创建失败.
        await loadBooks(1, pagination.itemPerPage)
        return
    }
    if (reloadPlanets === true) {
        // 先释放提交锁, 再刷新选项, 避免被 loadPlanetOptions 的防重入检查拦截.
        await loadPlanetOptions()
    }
    if (resultUnknown === true) {
        // 只重新读取, 不自动重发创建请求. 新书不一定在当前页.
        await refreshBooks()
    }
}

onMounted(refreshBooks)
</script>

提交校验和创建请求使用两个同级 try/catch。isSubmitting 覆盖校验与 POST 请求，期间禁用重复提交和关闭抽屉；提交后的读取在 finally 解锁之后执行，避免刷新函数被自身的防重入检查拦截。

loadBooks() 在补读末页后仍发现越界时，直接设置失败状态与错误提示，然后 return。try 内的 return 仍会执行 finally，因此加载状态会正常复位；catch 继续处理接口请求或响应校验失败。该分支不再通过 throw 跳转到本地 catch，也避免重复追加“请刷新重试”。读取失败由函数内部记录到页面状态中，JSDoc 不声明向调用方抛出这些错误。

08 / FLOW

分页和异常时的页面行为

  1. LIST读取当前页

    页面挂载时读取第一页，翻页或调整每页条数时再请求。加载过程中锁住分页与刷新入口。

  2. CREATE校验后提交

    书名修整、正整数排序和显示状态校验通过后，发送带真实天体 ID 的创建请求。

  3. CONFIRM确认结果再刷新

    成功后关闭抽屉并读取第一页；不确定时只读取核对，不自动重复创建。

场景行为
快速翻页或同时修改每页条数使用受控分页属性和加载锁，只允许一轮列表读取；忽略读取期间的新翻页事件，防止旧响应覆盖新页面。
空表后端 totalPage 为 0；页面保留第 1 页并显示真实空态。
页码超过最新末页读取有效末页一次；若再次变化导致仍越界，则显示可重试错误，避免无限请求。
列表读取失败显示错误与刷新入口，不用空表格冒充查无记录。
创建成功但列表刷新失败创建成功提示保留，失败说明显示在列表区域，不重复 POST。
天体引用失效先解锁，再刷新真实天体选项；失效选择清空，其他表单字段保留。
排序冲突保留全部输入，让用户改排序；不自动加 1，也不根据当前页推断空闲排序。
创建超时、断网或响应格式异常提示结果未确认，刷新当前页供核对；不关闭抽屉，不自动重发创建请求。
鉴权失效沿用统一处理与跳转，页面只结束自身状态，不重复弹窗。

后端按数值 planet_id ASC, sort ASC, id ASC 排序，再进行分页。这不是太阳到海王星的固定顺序，也不是创建时间倒序。新书可能出现在其他页；刷新第一页或当前页后没看到它，不能单凭这一点认定创建失败。核对相关页和记录后再决定是否重试。

同一天体的书籍可能跨页。当前页面只掌握一页记录，不能可靠计算“下一个未占用排序值”；最终由后端与唯一索引确认。

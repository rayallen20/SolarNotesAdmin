修改密码页面实现与 API 联调

管理员从「账号管理 → 修改密码」进入，填写原密码并确认新密码。后端确认成功后立即回到登录页，使用新密码建立新会话。

1. 后端核对

已实现　POST /v1/admin/password/change

改密需要当前管理员的 Bearer 令牌。后端从已鉴权的上下文取管理员 ID 和本次令牌摘要。原密码核验通过后，在同一事务里保存新密码摘要、清空当前令牌摘要，再返回成功。响应中没有新令牌。路由 · 控制器 · 事务写入

JSON请求体 · 仅示意字段，接入时传用户输入的原值
{
  "admin": {
    "current_password": "ExampleOld1",
    "new_password": "ExampleNew2"
  }
}
JSON成功响应 · Network 面板中的完整内容
{
  "code": 200,
  "message": "success",
  "data": {}
}
业务码后端含义页面反馈
200事务已提交，旧令牌已撤销。清空表单和本地会话，替换当前路由为登录页，提示使用新密码。
20006当前会话有效，原密码不正确。保留输入和会话，在原密码下提示并聚焦。
10101请求体或字段校验失败。留在表单纠正输入；联调时核对请求层级和长度。
20003 / 20004令牌过期 / 缺失、无效、已撤销或已被新会话替换。公共拦截器清理匹配的会话并返回登录页，页面结束处理。
10201 / 500数据库操作失败 / 内部错误。展示公共错误提示。

以上均为 HTTP 200 下的业务码，失败时 data 也是空对象。例如 20006 的 message 是「原密码不正确」。原密码仅要求非空白，支持历史长度；新密码须含非空白字符且为 6–20 个 Unicode 码点。两次新密码在浏览器逐字比较。前后端都使用原值，首尾空格也参与校验。后端允许新密码与原密码相同，成功时仍会撤销令牌。请求字段 · 非空白校验 · 响应封装

追加函数src/api/admin.js · 在文件末尾的 export 之前插入
/**
 * 提交当前管理员的原密码和新密码.
 * @param {string} currentPassword 原始输入的原密码.
 * @param {string} newPassword 原始输入的新密码.
 * @returns {Promise<void>} 后端确认写入后完成.
 */
async function changeAdminPassword(currentPassword, newPassword) {
    await request.post('/v1/admin/password/change', {
        admin: {
            current_password: currentPassword,
            new_password: newPassword,
        },
    })
}
替换导出src/api/admin.js · 替换原有的 export 块

    changeAdminPassword,
}

沿用文件顶部的 request。它会为受保护请求带上 Authorization: Bearer <access_token>，在业务成功时解包 payload.data，在失败时拒绝 Promise。本接口用 await 是否完成判断结果，无须读取令牌或再次判断 response.code。管理员请求模块 · 请求拦截器 · 公共错误处理

4. 让新密码能在登录页原样使用

登录和改密共用长度上下限及非空白判定。后端 notblank 使用 Go 的 strings.TrimSpace 判空。前端用 Unicode White_Space 属性检查是否含至少一个非空白码点；提交时保留完整字符串。这样即使密码包含表情或特殊空白字符，两页的判定也一致。

新增文件src/constants/adminPassword.js
/** @type {RegExp} 至少含一个 Go notblank 认可的非空白码点. */
const PASSWORD_TEXT_PATTERN = /\P{White_Space}/u

/** @type {number} 新密码和登录密码的最少码点数. */
const PASSWORD_MIN_LENGTH = 6

/** @type {number} 新密码和登录密码的最多码点数. */
const PASSWORD_MAX_LENGTH = 20

export {PASSWORD_TEXT_PATTERN, PASSWORD_MIN_LENGTH, PASSWORD_MAX_LENGTH}
追加导入src/views/LoginPage.vue · script setup 中

5. 实现修改密码页面

新建以下组件。页面从 Pinia 读取当前用户名，三个输入框各自控制明文显隐。「清空」恢复遮罩、清除提示并聚焦原密码。提交前逐项校验，提交期间锁定表单，回车和按钮走同一条提交路径。

新增文件src/views/ChangePasswordPage.vue · 完整组件
<template>
    <section class="password-page" aria-labelledby="password-title">
        <el-breadcrumb separator="/">
            <el-breadcrumb-item>管理后台</el-breadcrumb-item>
            <el-breadcrumb-item>账号管理</el-breadcrumb-item>
            <el-breadcrumb-item>修改密码</el-breadcrumb-item>
        </el-breadcrumb>

        <header class="heading">
            <el-icon class="lock" aria-hidden="true"><Lock /></el-icon>
            <div>
                <h1 id="password-title">修改密码</h1>
                <p>为当前账号 {{ userStore.username }} 设置新的登录密码.</p>
            </div>
        </header>

        <form ref="formElement" class="card" novalidate :aria-busy="pending"
              @submit.prevent="submit">
            <div class="fields">
                <div v-for="field in fields" :key="field.key" class="field">
                    <label :for="field.key">{{ field.label }}</label>
                    <el-input :id="field.key" v-model="values[field.key]" :name="field.key"
                              :type="revealed[field.key] ? 'text' : 'password'"
                              :autocomplete="field.autocomplete" :placeholder="field.placeholder"
                              :disabled="pending || needsLogin" required :spellcheck="false"
                              :aria-invalid="errors[field.key] !== ''"
                              :aria-describedby="field.key + '-feedback'"
                              :class="{invalid: errors[field.key] !== ''}"
                              @input="onEdit(field.key)" @blur="onBlur(field.key)">
                        <template #suffix>
                            <button type="button" class="eye" :aria-controls="field.key"
                                    :aria-label="(revealed[field.key] ? '隐藏' : '显示') + field.label"
                                    :disabled="pending || needsLogin"
                                    @click="revealed[field.key] = !revealed[field.key]">
                                <el-icon aria-hidden="true">
                                    <Hide v-if="revealed[field.key]" /><View v-else />
                                </el-icon>
                            </button>
                        </template>
                    </el-input>
                    <div :id="field.key + '-feedback'" aria-live="polite">
                        <p v-if="errors[field.key] !== ''" class="error">{{ errors[field.key] }}</p>
                        <p v-else-if="field.key === 'newPassword'" class="hint">使用 6-20 个字符.</p>
                    </div>
                </div>
            </div>

            <footer>
                <p v-if="notice !== ''" role="alert">{{ notice }}</p>
                <a v-if="needsLogin" :href="loginHref" @click="userStore.clearSession()">前往登录页</a>
                <div v-else class="actions">
                    <el-button :disabled="pending" @click="resetForm">清空</el-button>
                    <el-button native-type="submit" type="primary" :loading="pending" :disabled="pending">
                        确认修改
                    </el-button>
                </div>
            </footer>
        </form>
    </section>
</template>

<script setup>
import {nextTick, reactive, ref} from 'vue'
import {isNavigationFailure, useRouter} from 'vue-router'
import {ElMessage} from 'element-plus'
import {Hide, Lock, View} from '@element-plus/icons-vue'
import {changeAdminPassword} from '@/api/admin'
import {API_CODE} from '@/constants/apiCode'
import {PASSWORD_TEXT_PATTERN, PASSWORD_MIN_LENGTH, PASSWORD_MAX_LENGTH} from '@/constants/adminPassword'
import {getApiErrorCode, getApiErrorMessage, isAuthError} from '@/utils/apiError'
import useUserStore from '@/stores/user'

/** @typedef {'currentPassword' | 'newPassword' | 'confirmation'} PasswordField */

/** @type {{key: PasswordField, label: string, autocomplete: string, placeholder: string}[]} 字段显示顺序. */
const fields = [
    {key: 'currentPassword', label: '原密码', autocomplete: 'current-password', placeholder: '请输入原密码'},
    {key: 'newPassword', label: '新密码', autocomplete: 'new-password', placeholder: '请输入新密码'},
    {key: 'confirmation', label: '确认新密码', autocomplete: 'new-password', placeholder: '请再次输入新密码'},
]

/** @type {Record<PasswordField, string>} 仅保存在当前表单中的原始输入. */
const values = reactive({currentPassword: '', newPassword: '', confirmation: ''})
/** @type {Record<PasswordField, string>} 各字段的行内错误. */
const errors = reactive({currentPassword: '', newPassword: '', confirmation: ''})
/** @type {Record<PasswordField, boolean>} 各输入框是否显示明文. */
const revealed = reactive({currentPassword: false, newPassword: false, confirmation: false})
/** @type {import('vue').Ref<HTMLFormElement | null>} 原生表单, 用于定位输入框. */
const formElement = ref(null)
/** @type {import('vue').Ref<boolean>} 当前写请求是否正在处理. */
const pending = ref(false)
/** @type {import('vue').Ref<boolean>} 是否需要用户前往登录页核实结果. */
const needsLogin = ref(false)
/** @type {import('vue').Ref<string>} 表单级反馈. */
const notice = ref('')
/** 当前管理员会话. */
const userStore = /** @type {import('@/stores/user').UserStore} */ (useUserStore())
/** 当前路由实例. */
const router = useRouter()
/** @type {string} 含部署基础路径的登录地址. */
const loginHref = router.resolve({name: 'login'}).href

/**
 * 返回字段提示, 空字符串表示通过.
 * @param {PasswordField} key 字段名.
 * @returns {string} 字段级错误.
 */
function validateField(key) {
    const value = values[key]
    if (key === 'currentPassword') {
        return PASSWORD_TEXT_PATTERN.test(value) ? '' : '请输入原密码'
    }
    if (key === 'confirmation') {
        if (value === '') return '请再次输入新密码'
        return value === values.newPassword ? '' : '两次输入的新密码不一致'
    }
    if (PASSWORD_TEXT_PATTERN.test(value) === false) return '请输入新密码'
    const length = Array.from(value).length
    if (length < PASSWORD_MIN_LENGTH || length > PASSWORD_MAX_LENGTH) {
        return '新密码须为 6-20 个字符'
    }
    return ''
}

/**
 * 修正错误时重新校验. 新密码改变时同步检查已填写的确认项.
 * @param {PasswordField} key 刚编辑的字段.
 * @returns {void}
 */
function onEdit(key) {
    notice.value = ''
    if (errors[key] !== '') errors[key] = validateField(key)
    if (key === 'newPassword' && values.confirmation !== '') {
        errors.confirmation = validateField('confirmation')
    }
}

/**
 * 已填写字段失焦时校验. 服务端给出的原密码错误保留到下次编辑.
 * @param {PasswordField} key 失去焦点的字段.
 * @returns {void}
 */
function onBlur(key) {
    if (values[key] !== '' && errors[key] === '') errors[key] = validateField(key)
}

/**
 * 将焦点移至指定输入框.
 * @param {PasswordField} key 字段名.
 * @returns {void}
 */
function focusField(key) {
    const input = formElement.value?.elements.namedItem(key)
    if (input instanceof HTMLInputElement) input.focus()
}

/**
 * 清除所有输入及校验反馈, 恢复密码遮罩.
 * @returns {void}
 */
function clearFields() {
    for (const field of fields) {
        values[field.key] = ''
        errors[field.key] = ''
        revealed[field.key] = false
    }
    notice.value = ''
}

/**
 * 处理用户点击清空.
 * @returns {void}
 */
function resetForm() {
    clearFields()
    focusField('currentPassword')
}

/**
 * 后端已确认成功. 先清会话, 再在登录页显示成功原因.
 * @returns {Promise<void>}
 */
async function finishChange() {
    clearFields()
    needsLogin.value = true
    userStore.clearSession()
    try {
        const failure = await router.replace({name: 'login'})
        if (isNavigationFailure(failure) && router.currentRoute.value.name !== 'login') {
            notice.value = '密码已修改, 请前往登录页使用新密码重新登录.'
            return
        }
    } catch {
        notice.value = '密码已修改, 请前往登录页使用新密码重新登录.'
        return
    }
    ElMessage.success('密码已修改, 请使用新密码重新登录')
}

/**
 * 校验全部字段并提交一次. 回包只处理发起请求的会话.
 * @returns {Promise<void>}
 */
async function submit() {
    if (pending.value || needsLogin.value) return
    notice.value = ''
    /** @type {PasswordField | null} 首个需要修正的字段. */
    let firstInvalid = null
    for (const field of fields) {
        errors[field.key] = validateField(field.key)
        if (firstInvalid === null && errors[field.key] !== '') firstInvalid = field.key
    }
    if (firstInvalid !== null) {
        focusField(firstInvalid)
        return
    }

    const submittedToken = userStore.token
    pending.value = true
    try {
        await changeAdminPassword(values.currentPassword, values.newPassword)
    } catch (error) {
        if (isAuthError(error) || userStore.token !== submittedToken) return
        const code = getApiErrorCode(error)
        if (code === API_CODE.CURRENT_PASSWORD_INCORRECT) {
            errors.currentPassword = '原密码不正确, 请重新输入'
            pending.value = false
            await nextTick()
            focusField('currentPassword')
        } else if (code === undefined) {
            clearFields()
            needsLogin.value = true
            notice.value = '未能确认密码是否已修改, 请使用新密码登录核实.'
        } else {
            notice.value = getApiErrorMessage(error, '修改密码失败, 请稍后再试')
        }
        return
    } finally {
        pending.value = false
    }

    if (userStore.token === submittedToken) await finishChange()
}
</script>

开发环境与请求路径

在测试环境启动配置好的 Go 服务，确认它能访问测试库。前端使用现有 .env.development 和 Vite 代理；在前端工程执行下方命令，然后在同一浏览器登录测试管理员。若在虚拟机运行 Vite，代理目标的 127.0.0.1 指该虚拟机。Vite 配置

终端前端工程根目录
npm run dev

本机开发地址为 http://localhost:5062。打开「账号管理 → 修改密码」，在 Network 核对浏览器请求 POST /api/v1/admin/password/change，Vite 移除 /api 并转发到 http://127.0.0.1:4060/v1/admin/password/change。请求的 Content-Type 为 JSON，鉴权头为 Bearer。负载中的 admin 只含原密码和新密码。

用一次性测试账号走一遍

为验证新旧凭据，请准备两个不同的密码，并留在同一个测试会话中。可在本地接口客户端内存中保留首次登录时的令牌 A，便于在成功后单独验证旧令牌。

操作Network 与页面验收
未登录时直接打开 /admin/account/password；登录后从侧栏进入并刷新。未登录进入登录页。登录后可从「账号管理」展开唯一子项；直接刷新时分组展开且「修改密码」高亮。
分别试空白密码、5 和 21 个码点、两次新密码不一致；再试合法的 6 和 20 个码点。非法输入就地提示并聚焦首个错误，Network 没有改密请求。合法输入通过本地校验；可使用含表情和首尾空格的密码检查原值。
检查各输入的明文按钮，然后点击「清空」。仅对应字段切换显隐。清空后三项均被清除、恢复遮罩，焦点回到原密码。
使用有效会话提交错误的原密码。HTTP 200，业务码 20006。原密码行内提示，焦点回到该字段，新密码与确认值仍在。用该会话修正原密码后可以继续。
提交正确原密码，连续点击确认或按回车。仅发送一次改密请求，响应 200 / data: {}。自动到 /login 并看到成功提示，浏览器后退或直达受保护地址仍需登录。
在新登录前，用未过期的令牌 A 请求 GET /v1/planet/list；随后先用旧密码、再用新密码登录。令牌 A 返回 20004；旧密码登录返回 20001，新密码登录成功，新令牌可访问受保护接口。
同账号另一次登录替换旧令牌，再在持旧令牌的页面提交。业务码 20004（过期时为 20003）。只有公共过期或无效提示，页面回到登录。
模拟响应延迟超过 5 秒或连接中断。页面提示结果有待核实，提供前往登录页的入口。观察 Network 确认改密写请求未自动重发。

3. 请求地址与鉴权链路

现有 .env.development 已是 VITE_API_BASE_URL=/api。Vite 开发服务在 5062 端口，将 /api 前缀去除后转发到 http://127.0.0.1:4060，无需为新增接口分别配置代理。

浏览器：GET /api/v1/planet/status + Authorization: Bearer <access_token>
Vite：去掉 /api → GET http://127.0.0.1:4060/v1/planet/status
后端：校验 JWT 与数据库 token_hash → 执行状态查询 → 返回业务响应
Axios：code 200 解包 data；20003 / 20004 清会话并回登录页

后端仅豁免 POST /v1/admin/login；OPTIONS 预检在鉴权前已处理。受保护接口需要唯一的 Authorization: Bearer … 请求头。使用登录返回的 access_token，不从查询参数、请求体或 Cookie 传递。

后端会检查签名、时效及数据库中的 token_hash。同一账号再次成功登录后，旧 token 的后续请求会失败。当前没有刷新 token、服务端 logout 或 /me 接口，因此失效后重新登录，不自动重放创建请求。

前端路由守卫只检查本地 token 是否存在。即使地址能进入后台，后端仍会独立验证令牌；真正的接口访问权限由后端决定。

生产部署不使用 Vite 开发代理。目前 .env.production 仍是 http://localhost:8080，发布前需要配置实际 API 地址；若也使用 /api，需要部署服务器提供反向代理。

export {API_CODE}

@enum {number} 是 JavaScript 的 JSDoc 类型说明，不是 TypeScript enum。API_CODE 以具名方式导出，使用时写 import {API_CODE} from '@/constants/apiCode'。数值只在此处定义；其他业务判断使用具有含义的成员名。

例如令牌判断使用 API_CODE.TOKEN_EXPIRED / API_CODE.TOKEN_INVALID，天体冲突使用 API_CODE.BODY_ALREADY_EXISTS。后端新增业务码时在这里补充，再在对应功能中添加处理分支。

error.response.status >= 500 判断的是 HTTP 5xx 范围，保留该写法；不要替换为 API_CODE.INTERNAL_ERROR。后者只表示响应体中的业务内部错误。后面的 JSON 响应示例、协议表仍保留数字，便于核对网络响应。

5.1 新增共享类型工具：typeGuard.js

将 isObject() 与 isRecord() 集中到 src/utils/typeGuard.js。isRecord() 复用 isObject()，再排除数组；两个函数均不依赖错误处理、请求或天体业务模块。

src/utils/typeGuard.js点击折叠 / 展开
/**
 * 判断输入是否为非 null 的对象，数组也会通过此检查。
 * @param {unknown} value 待检查的值。
 * @returns {value is Record<string, unknown>} 是对象时返回 true。
 */
function isObject(value) {
    return typeof value === 'object' && value !== null
}

/**
 * 判断输入是否为非 null、非数组的对象。
 * @param {unknown} value 待检查的值。
 * @returns {value is Record<string, unknown>} 满足条件时返回 true。
 */
function isRecord(value) {
    if (isObject(value) === false) {
        return false
    }

    return Array.isArray(value) === false
}

export {isObject, isRecord}

apiError.js 和 request.js 均删除原有 isObject() 定义，改用 import {isObject} from '@/utils/typeGuard'。body.js 删除原有 isRecord() 定义，改用 import {isRecord} from '@/utils/typeGuard'。两个函数均保留 JSDoc 类型谓词 value is Record<string, unknown>，使 IDE 在判断通过后能够继续检查字段类型。

isObject() 接受非 null 对象，数组也会通过；isRecord() 还要求 Array.isArray(value) === false。两者都不保证值是普通对象，也不验证字段内容。第 6 节继续使用 isRecord()，因此数组仍会被拒绝；本次只集中定义位置，保持原有校验规则。

5.2 新增字段读取工具：fieldReader.js

将 readStringField() 和 readRequiredStringField() 移入 src/utils/fieldReader.js。前者返回字符串字段，后者复用前者并拒绝空字符串。与返回布尔值的 typeGuard 不同，字段工具返回读取结果，校验失败时抛出异常。

src/utils/fieldReader.js点击折叠 / 展开
/**
 * 读取一个字符串字段，保留输入对象中的原值。
 * @param {Record<string, unknown>} record 待检查的记录。
 * @param {string} field 字段名。
 * @returns {string} 已确认类型的字段值。
 * @throws {Error} 字段缺失或类型错误时抛出。
 */
function readStringField(record, field) {
    /** @type {unknown} 待校验的字段值。 */
    const value = record[field]

    if (typeof value !== 'string') {
        throw new Error('接口响应中的 ' + field + ' 字段类型异常')
    }

    return value
}

/**
 * 读取必须非空的字符串字段；复用字符串读取函数，不执行 trim。
 * @param {Record<string, unknown>} record 待检查的记录。
 * @param {string} field 字段名。
 * @returns {string} 非空字符串。
 * @throws {Error} 字段缺失、类型错误或为空时抛出。
 */
function readRequiredStringField(record, field) {
    /** @type {string} 已确认类型的字段值。 */
    const value = readStringField(record, field)

    if (value === '') {
        throw new Error('接口响应中的 ' + field + ' 字段不能为空')
    }

    return value
}

export {readStringField, readRequiredStringField}

该模块使用通用的“接口响应中的”错误说明，不包含天体业务文案。两个函数的 record 参数均要求对象；调用方先用 isRecord() 确认对象形态，再读取字段，继续分别检查业务约束。

保持原有语义：readStringField() 接受空字符串；readRequiredStringField() 拒绝 ''，但保留 ' ' 及字符串的首尾空白，不做 trim 或类型转换。天体表单提交前的 trim 仍由该业务自己的代码决定。

5.3 新增公共错误模块：apiError.js

任何页面都可以使用 getApiErrorMessage(error, fallback)，它不再硬编码“天体、标题和简介”等业务提示。公共函数只返回值，不弹窗、不修改 Store、不跳转路由，也不导入 request.js，避免依赖循环。

getApiErrorCode() 返回可按业务错误处理的 code。超时、无响应和 HTTP 5xx 优先按传输异常处理，返回 undefined，使页面转交公共函数；即使 HTTP 503 的响应体恰好包含某个业务码，也不会被误报为表单错误。

src/utils/apiError.js点击折叠 / 展开
import {isObject} from '@/utils/typeGuard'
import axios from 'axios'
import {API_CODE} from '@/constants/apiCode'

/**
 * 提取可按业务错误处理的 code。
 * 超时、未收到响应或 HTTP 5xx 时返回 undefined，优先交给公共错误提示处理。
 * @param {unknown} error 业务错误或 Axios 异常。
 * @returns {number | undefined} 可用的业务码；不存在或应优先处理传输错误时返回 undefined。
 */
function getApiErrorCode(error) {
    if (axios.isAxiosError(error) === true) {
        if (error.code === 'ECONNABORTED' || error.code === 'ETIMEDOUT') {
            return undefined
        }
        if (error.response === undefined || error.response.status >= 500) {
            return undefined
        }
        error = error.response.data
    }
    if (isObject(error) === true && typeof error.code === 'number') {
        return error.code
    }
    return undefined
}

/**
 * 判断后端是否明确拒绝了登录令牌。
 * @param {unknown} error 业务错误或 Axios 异常。
 * @returns {boolean} 业务码表示令牌过期或无效时返回 true。
 */
function isAuthError(error) {
    /** @type {number | undefined} 可用业务码。 */
    const code = getApiErrorCode(error)
    return code === API_CODE.TOKEN_EXPIRED || code === API_CODE.TOKEN_INVALID
}

/**
 * 生成公共错误说明，不包含天体、用户名或密码等页面业务文案。
 * 本函数只返回文字，不弹窗、不清理会话、不跳转路由。
 * @param {unknown} error 业务错误或 Axios 异常。
 * @param {string} fallback 没有可用错误信息时显示的备用文字。
 * @returns {string} 可供调用方展示的错误说明。
 */
function getApiErrorMessage(error, fallback) {
    if (axios.isAxiosError(error) === true) {
        if (error.code === 'ECONNABORTED' || error.code === 'ETIMEDOUT') {
            return '请求超时，请稍后刷新重试'
        }
        if (error.response === undefined) {
            return '暂时无法连接服务，请检查网络或后端是否启动'
        }
        if (error.response.status >= 500) {
            return '服务暂时不可用，请稍后重试'
        }
        error = error.response.data
    }
    switch (getApiErrorCode(error)) {
        case API_CODE.VALIDATION_ERROR:
            return '请求参数不符合要求，请检查后重试'
        case API_CODE.TOKEN_EXPIRED:
            return '登录已过期，请重新登录'
        case API_CODE.TOKEN_INVALID:
            return '登录状态无效，请重新登录'
        case API_CODE.DATABASE_ERROR:
        case API_CODE.INTERNAL_ERROR:
            return '服务暂时不可用，请稍后重试'
    }
    if (isObject(error) === true && typeof error.message === 'string') {
        if (error.message.trim() !== '') {
            return error.message
        }
    }
    return fallback
}

export {getApiErrorCode, getApiErrorMessage, isAuthError}

页面先匹配自身业务码，再调用公共函数。fallback 仅在公共函数找不到明确分类或非空 message 时使用，不强行覆盖后端返回的有效说明。

5.4 更新请求模块：request.js

用下方完整文件替换请求模块。它从 typeGuard.js 导入 isObject()，从 apiError.js 导入公共错误工具，不再重复定义或转导出这些工具。页面需要同步把错误工具的导入路径改为 @/utils/apiError，API 请求模块仍从 @/utils/request 导入默认请求实例。

 * @param {import('axios').InternalAxiosRequestConfig} requestConfig 请求配置。
 * @returns {import('axios').InternalAxiosRequestConfig} 处理后的配置。
 */
function attachToken(requestConfig) {
    /** 当前 Pinia 的用户 Store。 */
    const userStore = /** @type {import('@/stores/user').UserStore} */ (useUserStore(pinia))
    if (requestConfig.url === '/v1/admin/login' || userStore.token === '') {
        requestConfig.headers.delete('Authorization')
    } else {
        requestConfig.headers.set('Authorization', 'Bearer ' + userStore.token)
    }
    return requestConfig
}

/**
 * 清理失效会话并返回登录页；迟到的旧令牌错误不得清理新会话。
 * @param {unknown} error 后端鉴权错误。
 * @param {import('axios').InternalAxiosRequestConfig} requestConfig 原请求配置。
 * @returns {Promise<void>} 会话失效处理结束。
 */
async function handleAuthFailure(error, requestConfig) {
    if (requestConfig.url === '/v1/admin/login') {
        return
    }
    /** 当前 Pinia 的用户 Store。 */
    const userStore = /** @type {import('@/stores/user').UserStore} */ (useUserStore(pinia))
    /** @type {string} 当前会话应携带的 Authorization 值。 */
    let currentAuthorization = ''
    if (userStore.token !== '') {
        currentAuthorization = 'Bearer ' + userStore.token
    }
    /** 原请求实际发出的 Authorization 值。 */
    const sentHeader = requestConfig.headers.get('Authorization')
    /** @type {string} 规范化的原请求头。 */
    let sentAuthorization = ''
    if (typeof sentHeader === 'string') {
        sentAuthorization = sentHeader
    }
    if (sentAuthorization !== currentAuthorization || isHandlingAuthFailure === true) {
        return
    }
    isHandlingAuthFailure = true
    try {
        userStore.clearSession()
        if (router.currentRoute.value.name !== 'login') {
            ElMessage.warning(getApiErrorMessage(error, '请重新登录'))
            /** 路由跳转结果。 */
            const failure = await router.replace({name: 'login'})
            if (isNavigationFailure(failure) === true) {
                ElMessage.error('未能打开登录页，请手动进入 /login 重新登录')
            }
        }
    } catch {
        ElMessage.error('登录状态清理或跳转失败，请手动进入 /login 重新登录')
    } finally {
        isHandlingAuthFailure = false
    }
}

/**
 * 按业务码处理响应，只在成功时解包 data。
 * @param {import('axios').AxiosResponse} response HTTP 响应。
 * @returns {Promise<any>} 解包后的业务数据；失败时保持 Promise 拒绝。
 */
async function unwrapResponse(response) {
    /** @type {unknown} 待检查的响应包。 */
    const payload = response.data
    if (isObject(payload) === false || typeof payload.code !== 'number') {
        throw new Error('接口响应格式异常，请稍后重试')
    }
    if (payload.code === API_CODE.SUCCESS) {
        return payload.data
    }
    if (isAuthError(payload) === true) {
        await handleAuthFailure(payload, response.config)
    }
    return Promise.reject(payload)
}

 * @param {unknown} data request 响应拦截器返回的 payload.data。
 * @returns {unknown[]} 尚未逐项校验的数组。

function readPlanets(data) {
    if (isRecord(data) === false) {
        throw new Error('天体接口响应格式异常，请刷新后重试')
    }

    if (Array.isArray(data.planets) === false) {
        throw new Error('天体接口响应缺少 planets 数组')
    }

    return data.planets
}

/**
 * 判断状态项的名称是否属于当前前端支持的九个选项。
 * @param {string} name 待检查的天体标识。
 * @returns {boolean} 名称精确匹配时返回 true。
 */
function isKnownBodyName(name) {
    for (const option of bodyOptions) {
        if (option.name === name) {
            return true
        }
    }

    return false
}

/**
 * 获取下拉选项状态；任何缺失、重复或格式错误都视为加载失败。
 * @returns {Promise<BodyStatus[]>} 包含全部九个天体的有效状态。
 * @throws {Error} 响应结构或状态字段不符合当前协议时拒绝。
 */
async function getBodyStatus() {
    /** @type {unknown} 已解包的响应 data，不再读取一层 data。 */
    const data = await request.get('/v1/planet/status')
    /** @type {unknown[]} 未经校验的状态项。 */
    const planets = readPlanets(data)
    /** @type {Set<string>} 已出现的名称，防止重复项冒充完整状态。 */
    const seenNames = new Set()
    /** @type {BodyStatus[]} 返回给组件的已校验状态。 */
    const result = []

    for (const item of planets) {
        if (isRecord(item) === false) {
            throw new Error('天体状态记录格式异常')
        }

        /** @type {string} 状态项中的精确名称。 */
        const name = readRequiredStringField(item, 'name')

        if (isKnownBodyName(name) === false || seenNames.has(name) === true) {
            throw new Error('天体状态包含未知或重复的名称')
        }

        if (typeof item.exist !== 'boolean') {
            throw new Error('天体状态中的 exist 必须为布尔值')
        }

        seenNames.add(name)
        result.push({name: name, exist: item.exist})
    }

    if (seenNames.size !== bodyOptions.length) {
        throw new Error('天体状态不完整，请刷新状态后重试')
    }

    return result
}

/**
 * 读取已创建的天体列表，保留后端顺序和历史未知名称。
 * @returns {Promise<BodyRecord[]>} 空表返回空数组，不补齐未创建天体。
 * @throws {Error} 列表字段缺失或类型错误时拒绝。
 */
async function getBodyList() {
    /** @type {unknown} 已解包的响应 data。 */
    const data = await request.get('/v1/planet/list')
    /** @type {unknown[]} 未经校验的天体记录。 */
    const planets = readPlanets(data)
    /** @type {BodyRecord[]} 返回给页面的天体列表。 */
    const result = []

    for (const item of planets) {
        if (isRecord(item) === false) {
            throw new Error('天体列表记录格式异常')
        }

        /** @type {string} 保持为字符串的天体 ID。 */
        const id = readRequiredStringField(item, 'id')
        /** @type {string} 不转换大小写的名称。 */
        const name = readRequiredStringField(item, 'name')
        /** @type {string} 数据库中的标题。 */
        const title = readStringField(item, 'title')
        /** @type {string} 数据库中的简介。 */
        const intro = readStringField(item, 'intro')

        result.push({id: id, name: name, title: title, intro: intro})
    }

    return result
}

/**
 * 创建天体；表单校验由组件执行，重复名称由后端最终判定。
 * @param {AddBodyForm} form 已通过前端校验的三个必填字段。
 * @returns {Promise<void>} 后端确认创建成功，不返回新记录或 ID。
 * @throws {Error} 成功响应结构异常时拒绝；业务及网络错误直接向外传递。

async function addBody(form) {

            name: form.name,
            title: form.title.trim(),

        throw new Error('创建接口响应格式异常，请刷新列表确认结果')
    }
}

/**
 * @typedef {Object} LoginAdmin 登录接口返回的管理员信息
 * @property {string} id 管理员 ID,保留字符串形式
 * @property {string} username 服务端返回的管理员用户名
 * @property {string} access_token 服务端签发的访问令牌

import request from "@/utils/request";

/**
 * 本函数用于请求管理员登录接口,并从解包后的数据中取得管理员信息
 * @param {string} username 用户输入的用户名
 * @param {string} password 用户输入的原始密码,不做 trim 或前端哈希
 * @returns {Promise<LoginAdmin>} 已检查字段类型的管理员信息
 * @throws {Error} 响应格式异常时拒绝;业务错误和网络错误直接向调用方传递
 * */
async function loginAdmin(username, password) {
    /** @type {LoginRequest} 管理员登录接口的请求体 */
    const body = {
        admin: {
            username: username,
            password: password,
        },
    }

    /**
     * request 的响应拦截器(已经返回 payload.data)
     * 先作为 unknown 检查,避免误用 AxiosResponse 类型或未经校验的数据
     * @type {unknown}
     */
    const data = await request.post('/v1/admin/login', body)
    if (typeof data !== 'object' || data === null || ('admin' in data) === false) {
        throw new Error('登录响应格式异常，请稍后重试')
    }

    /** @type {unknown} 待检查的管理员信息 */
    const admin = data.admin
    if (typeof admin !== 'object' || admin === null) {
        throw new Error('登录响应缺少管理员信息,请稍后重试')
    }

    if (hasValidAdminId(admin) === false) {
        throw new Error('登录响应中的管理员信息不完整,请稍后重试')
    }

    if (hasValidAdminUsername(admin) === false) {
        throw new Error('登录响应中的管理员信息不完整,请稍后重试')
    }

    if (hasValidAdminAccessToken(admin) === false) {
        throw new Error('登录响应中的管理员信息不完整,请稍后重试')
    }

    return {
        id: admin.id,
        username: admin.username,
        access_token: admin.access_token,
    }
}

/**
 * 本函数用于检查管理员信息中的 id 字段是否存在且为非空字符串
 * @param {unknown} admin 待检查的管理员信息
 * @returns {admin is {id: string}} id 字段通过校验时返回 true
 * */
function hasValidAdminId(admin) {
    if (typeof admin !== 'object' || admin === null) {
        return false
    }

    if (('id' in admin) === false || typeof admin.id !== 'string') {
        return false
    }

    return admin.id !== ''
}

    }

    if (('username' in admin) === false || typeof admin.username !== 'string') {

    }

}

 * 本函数用于检查管理员信息中的 access_token 字段是否存在且为非空字符串

刷新整个浏览器列表仍来自数据库，记录保留，不再显示“内存演示”通知。
空白标题 / 超长简介前端表单报错且不发 POST；若绕过前端提交非法数据，后端返回 10101。
两个标签页先打开同一可用天体，再先后提交共用当前有效会话；第一条成功，另一条收到 20101，保留标题简介并刷新状态。不要在测试中重新登录同一账号，否则会先触发旧令牌失效。
在另一个浏览器重新登录同一管理员，再刷新原页面原令牌被撤销，GET 返回 HTTP 200 / code 20004；原页面只提示一次并返回登录页。
令牌自然过期返回 20003，清理本地两个会话键并返回登录页。篡改 token 只能验证 20004，不能代替过期测试。
只让 status 请求失败列表仍显示；下拉全部禁用，提供刷新状态按钮。缺少状态、重复名称、exist 是字符串时也应视为失败。
只让 list 请求失败显示列表错误提示，可刷新；不能把失败画成“暂无天体”。
创建成功后让后续 GET 失败仍提示创建成功，刷新区域显示失败；恢复后刷新，不再次创建同一天体。
快速双击确认 / 连续触发表单提交校验阶段就加锁，最多发送一个创建 POST。
检查本地存储仅沿用现有 token 与 username，不保存管理员密码，不伪造 ID。

状态失败、过期、并发和迟到响应等异常场景可通过临时模拟响应或浏览器请求拦截测试。真实写入测试应选未创建的天体；当前 API 未提供删除接口，不要为了测试随意删除已有业务记录。

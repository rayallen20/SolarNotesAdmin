1. 本次实现的页面与边界

沿用现有布局：左侧第一个菜单改为天体管理，右侧顶部继续显示当前页面标题及用户信息，右侧内容区展示天体列表。点击卡片右上角的添加天体，从右侧打开抽屉，填写后提交。

选择天体→填写简介→校验并提交→关闭抽屉、刷新列表

本阶段先完成前端交互。管理端的真实新增接口尚未确认，本文的 src/api/body.js 使用内存数据，提供与后续请求一致的异步函数入口。刷新整个浏览器后演示数据会清空；切换菜单再返回仍可看到本次浏览中添加的记录。

这里添加的是天体简介记录。太阳与八大行星的模型已由前台静态配置创建；新增简介不会自动生成新的三维模型。页面术语统一为“天体”，现有数据库表及已核实的列表接口仍采用 planet 命名。

九个可选标识为 Sun、Mercury、Venus、Earth、Mars、Jupiter、Saturn、Uranus、Neptune。大小写必须与前台的 config.name 完全一致。

字段页面设计依据
name必选下拉框；显示“地球（Earth）”，提交 Earth；已添加项禁选前台按 name 精确匹配；数据库有唯一索引 uk_name
title本页要求必填，去除首尾空白后 1～20 字符数据库字段注释中的业务上限为 20；列容量为 50
intro本页要求必填，去除首尾空白后 1～150 字符数据库字段注释中的业务上限为 150；列容量为 255
id通过服务层取得，表单不填写；示例为 demo-body-* 字符串真实数据库为雪花 BIGINT，注释要求程序使用字符串

上述必填规则属于本页设计，真实后端校验规则仍需对齐。标题和简介按普通文本展示，使用 Vue 插值，不使用 v-html。

5. 定义数据类型与演示数据入口

当前模块从空列表开始。通过异步 getBodyList() 和 addBody(form) 隔离页面与数据来源，后续接真实接口时可以保持页面调用方式一致。这里重新检查未知标识、重复添加和字段长度，便于单独验证服务层行为。

src/api/body.js点击折叠 / 展开
import {
    bodyOptions,
    BODY_TITLE_MAX_LENGTH,
    BODY_INTRO_MAX_LENGTH,
} from '@/constants/body'

/**
 * @typedef {Object} BodyRecord 天体列表中的一条记录。
 * @property {string} id 天体 ID；真实接口应将数据库 BIGINT 以字符串传输。
 * @property {string} name 与三维场景 config.name 一致的匹配标识。
 * @property {string} title 简介标题。
 * @property {string} intro 简介内容。
 */

/**
 * @typedef {Object} AddBodyForm 添加天体时提交的数据。
 * @property {string} name 从固定选项中选择的匹配标识。
 * @property {string} title 简介标题。
 * @property {string} intro 简介内容。
 */

/**
 * 当前页面演示使用的内存数据；刷新整个浏览器后会清空。
 * @type {BodyRecord[]}
 */
const memoryBodies = []

/**
 * 演示记录的递增序号，仅用于构造列表的字符串 ID。
 * @type {number}
 */
let nextDemoId = 1

/**
 * 读取天体列表。切换页面后重新进入，仍可读取本次浏览中的演示数据。
 * @returns {Promise<BodyRecord[]>} 记录的副本，避免页面直接修改数据源。
 */
async function getBodyList() {
    /** @type {BodyRecord[]} 返回给页面的记录列表。 */
    const result = []

    for (const body of memoryBodies) {
        result.push({...body})
    }

    return result
}

/**
 * 添加一条天体简介。当前实现仅操作内存，后续用真实请求替换。
 * @param {AddBodyForm} form 表单数据，三个字段均为必填字符串。
 * @returns {Promise<void>} 添加完成。
 * @throws {Error} 天体未知、已存在或简介不符合本页规则时拒绝操作。
 */
async function addBody(form) {
    /** @type {string} 保持原样的匹配标识，不转换大小写或删除空格。 */
    const name = form.name
    /** @type {string} 去除首尾空白后的简介标题。 */
    const title = form.title.trim()
    /** @type {string} 去除首尾空白后的简介内容。 */
    const intro = form.intro.trim()
    /** @type {boolean} 标识是否属于已知天体。 */
    let isKnownBody = false

    for (const option of bodyOptions) {
        if (option.name === name) {
            isKnownBody = true
            break
        }
    }

    if (isKnownBody === false) {
        throw new Error('请选择列表中提供的天体')
    }

    for (const body of memoryBodies) {
        if (body.name === name) {
            throw new Error('该天体已经添加，请选择其他天体')
        }
    }

    if (title === '' || title.length > BODY_TITLE_MAX_LENGTH) {
        throw new Error('简介标题应为 1 至 20 个字符')
    }

    if (intro === '' || intro.length > BODY_INTRO_MAX_LENGTH) {
        throw new Error('简介内容应为 1 至 150 个字符')
    }

    /** @type {BodyRecord} 即将加入内存列表的记录。 */
    const body = {
        id: `demo-body-${nextDemoId}`,
        name,
        title,
        intro,
    }

    memoryBodies.push(body)
    nextDemoId += 1
}

export {getBodyList, addBody}

这份代码的添加结果只在内存中。demo-body-* 是演示 ID，不是雪花 ID。页面里的“刷新列表”重新读取内存，浏览器整体刷新会重新初始化该模块。切换为真实 API 时应整体替换演示实现，使用后端生成的 ID。

7. 实现天体列表和添加抽屉

保存下面完整组件。结构采用 template → script → style；脚本使用普通函数、完整 JSDoc、显式比较。列表使用 el-table，新增表单使用 el-drawer 和 el-form。组件用法可对照 Table 官方文档、Drawer 官方文档 与 Form 官方文档。

  • 列表读取失败时显示重试提示，并禁用添加，避免依据不完整的列表判断可选天体。
  • 标题和简介在提交前去除首尾空白；空白文本无法通过校验。
  • 从校验开始就锁定提交，避免快速重复点击；提交期间禁用取消及关闭操作。
  • 添加失败保留输入；添加成功关闭抽屉、显示结果并重新读取列表。
  • 添加成功后的列表刷新若失败，由列表单独显示错误，避免将已成功的添加误报为失败。
  • 九个天体全部添加后，添加按钮禁用；本阶段不需要分页、编辑或删除按钮。

<script setup>
import {computed, nextTick, onMounted, reactive, ref} from 'vue'
import {ElMessage} from 'element-plus'
import {ArrowRight, Plus, Refresh} from '@element-plus/icons-vue'
import {getBodyList, addBody} from '@/api/body'
import {
    bodyOptions,
    BODY_TITLE_MAX_LENGTH,
    BODY_INTRO_MAX_LENGTH,
} from '@/constants/body'

defineOptions({
    name: 'BodyListPage',
})

/** @type {import('vue').Ref<import('@/api/body').BodyRecord[]>} 天体列表。 */
const bodyList = ref([])
/** @type {import('vue').Ref<boolean>} 是否正在读取列表。 */
const loading = ref(false)
/** @type {import('vue').Ref<boolean>} 最近一次读取列表是否失败。 */
const loadFailed = ref(false)
/** @type {import('vue').Ref<boolean>} 添加抽屉是否显示。 */
const drawerVisible = ref(false)
/** @type {import('vue').Ref<boolean>} 是否正在校验或提交添加表单。 */
const submitting = ref(false)
/** @type {import('vue').Ref<import('element-plus').FormInstance | null>} 表单组件实例。 */
const addFormRef = ref(null)

/** @type {import('@/api/body').AddBodyForm} 添加天体的表单数据。 */
const addForm = reactive({
    name: '',
    title: '',
    intro: '',
})

/** @type {import('element-plus').FormRules<import('@/api/body').AddBodyForm>} 表单校验规则。 */
const addFormRules = {
    name: [
        {required: true, message: '请选择天体', trigger: 'change'},
    ],
    title: [
        {required: true, whitespace: true, message: '请输入简介标题', trigger: 'blur'},
        {max: BODY_TITLE_MAX_LENGTH, message: '简介标题最多 20 个字符', trigger: 'blur'},
    ],
    intro: [
        {required: true, whitespace: true, message: '请输入简介内容', trigger: 'blur'},
        {max: BODY_INTRO_MAX_LENGTH, message: '简介内容最多 150 个字符', trigger: 'blur'},
    ],
}

/** @type {import('vue').ComputedRef<number>} 尚未添加的天体数量。 */
const availableBodyCount = computed(getAvailableBodyCount)

/**
 * 获取用于列表展示的天体中文名称。
 * @param {string} name 天体的匹配标识。
 * @returns {string} 对应的中文名称；未知标识直接显示原值。
 */
function getBodyLabel(name) {
    for (const option of bodyOptions) {
        if (option.name === name) {
            return option.label
        }
    }

    return name
}

/**
 * 判断给定天体是否已经出现在当前列表中。
 * @param {string} name 天体的匹配标识。
 * @returns {boolean} 已添加时返回 true。
 */
function isBodyAdded(name) {
    for (const body of bodyList.value) {
        if (body.name === name) {
            return true
        }
    }

    return false
}

/**
 * 计算固定选项中尚未添加的数量。
 * @returns {number} 可继续添加的天体数量。
 */
function getAvailableBodyCount() {
    /** @type {number} 尚未添加的数量。 */
    let count = 0

    for (const option of bodyOptions) {
        if (isBodyAdded(option.name) === false) {
            count += 1
        }
    }

    return count
}

/**
 * 从错误对象中读取可展示的信息，兼容 Error 与接口业务错误。
 * @param {unknown} error 捕获到的异常。
 * @param {string} fallback 没有可用错误信息时显示的文字。
 * @returns {string} 错误信息。
 */
function getErrorMessage(error, fallback) {
    if (typeof error === 'object' && error !== null && 'message' in error) {
        if (typeof error.message === 'string' && error.message.trim() !== '') {
            return error.message
        }
    }

    return fallback
}

/**
 * 读取列表；失败时保留错误状态并允许重新刷新。
 * @returns {Promise<void>} 本次读取结束。
 */
async function loadBodies() {
    if (loading.value === true) {
        return
    }

    loading.value = true
    loadFailed.value = false

    try {
        bodyList.value = await getBodyList()
    } catch (error) {
        loadFailed.value = true
        ElMessage.error(getErrorMessage(error, '天体列表加载失败'))
    } finally {
        loading.value = false
    }
}

/**
 * 清空表单内容及校验提示，供抽屉关闭或重新打开时使用。
 * @returns {void}
 */
function resetAddForm() {
    addForm.name = ''
    addForm.title = ''
    addForm.intro = ''

    if (addFormRef.value !== null) {
        addFormRef.value.clearValidate()
    }
}

/**
 * 打开添加抽屉，等待懒加载的表单挂载后清除旧校验信息。
 * @returns {Promise<void>} 抽屉内容已完成本轮更新。
 */
async function openAddDrawer() {
    if (loading.value === true || loadFailed.value === true || submitting.value === true) {
        return
    }

    if (availableBodyCount.value === 0) {
        return
    }

    resetAddForm()
    drawerVisible.value = true
    await nextTick()

    if (addFormRef.value !== null) {
        addFormRef.value.clearValidate()
    }
}

/**
 * 响应抽屉关闭动作，在提交期间阻止通过关闭按钮等途径离开。
 * @param {() => void} done Element Plus 提供的关闭回调。
 * @returns {void}
 */
function beforeCloseDrawer(done) {
    if (submitting.value === true) {
        return
    }

    done()
}

/**
 * 响应取消按钮，提交期间保持抽屉打开。
 * @returns {void}
 */
function closeAddDrawer() {
    if (submitting.value === true) {
        return
    }

    drawerVisible.value = false
}

/**
 * 校验表单并添加天体，成功后关闭抽屉并重新读取列表。
 * @returns {Promise<void>} 本次提交处理结束。
 */
async function submitBody() {
    if (submitting.value === true || drawerVisible.value === false) {
        return
    }

    if (addFormRef.value === null) {
        return
    }

    submitting.value = true

    try {
        addForm.title = addForm.title.trim()
        addForm.intro = addForm.intro.trim()

        /** @type {boolean} Element Plus 表单校验结果。 */
        const isValid = await addFormRef.value.validate()

        if (isValid === false) {
            submitting.value = false
            return
        }
    } catch {
        // 校验失败时表单项已经显示提示，保留用户输入并解除提交锁。
        submitting.value = false
        return
    }

    try {
        await addBody({
            name: addForm.name,
            title: addForm.title,
            intro: addForm.intro,
        })
    } catch (error) {
        ElMessage.error(getErrorMessage(error, '天体添加失败，请重试'))
        return
    } finally {
        submitting.value = false
    }

    drawerVisible.value = false
    ElMessage.success('天体添加成功（演示）')
    // 读取失败由 loadBodies() 单独处理，避免误报为添加失败。
    await loadBodies()
}

onMounted(loadBodies)
</script>

这里几个容易忽略的细节

submitBody() 使用两个同级的 try...catch：第一个处理表单校验，第二个处理添加请求。validate() 的 Promise 校验失败可能拒绝，示例捕获后保留表单内的提示，并在提前返回前解除提交锁；请求阶段通过 finally 统一解除提交锁。添加成功后的关闭抽屉、成功提示与列表刷新放在两个块之后，列表刷新失败仍由 loadBodies() 单独处理。

抽屉首次打开时表单才挂载，因此通过 nextTick() 等待组件更新，再清除校验消息。关闭后同时清空模型和校验提示，下一次打开从空表单开始。

size="min(520px, 100vw)" 让抽屉在桌面宽度为 520px，在窄屏占满可用宽度。表格的简介列允许换行；横向空间不足时由表格内部滚动。

12. 后续接真实 API 时如何衔接

目前已核实的是前台工程 SolarNotesFrontend/src/api/planet.js 使用 GET /v1/planet/list。它的响应拦截器先返回业务响应的 data，业务函数取得其中的 planets 数组，再按记录的 name 与场景配置匹配。管理端是否复用该接口以及鉴权规则，接入时再确认。

模块入口接入真实接口时的约定
getBodyList()继续返回 Promise<BodyRecord[]>。若复用已有列表接口，在 API 模块中把解包后的 {planets: [...]} 转成数组返回给页面。
addBody(form)确认新增接口的路径、方法、请求体嵌套方式和业务成功码后再封装；继续返回 Promise<void>，添加失败时拒绝 Promise。
Axios 入口复用工程的 @/utils/request；该实例已经返回业务 payload.data，避免再误读一层 Axios response.data。
错误与重复控制按后端错误消息字段调整 getErrorMessage()；服务端仍须校验已知 name、业务长度和唯一性，处理并发重复添加。
ID 与记录时间ID 由后端生成；BIGINT 在 JSON 中以字符串提供。记录时间按服务端与数据库约定管理。
页面提示接通真实接口后移除演示数据提示，将成功文字改为“天体添加成功”。

新增接口路径和返回格式尚未确认，因此本文没有把推测的新增 URL 写成现成接口。前端页面只依赖这两个异步入口，后续可以集中替换数据模块。
